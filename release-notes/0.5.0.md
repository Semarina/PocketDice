### Highlights

* Minecraft 26.2 support for Paper/Purpur/Folia and Fabric/Quilt.
* Dedicated Paper and Fabric builds continue in this release.
* Dice shorthand such as `/roll d8` is now always enabled.
* Removed the `allow_shorthand` and legacy `allow_shorthand_d` configuration switches.
* Java 25 remains required.

* * *

### ⚠️ Platform & artifact selection (IMPORTANT)

`v0.5.0` publishes two JARs for Minecraft 26.2:

* `PocketDice-0.5.0-Paper.jar` — Use this for Paper / Purpur / Folia servers.
* `PocketDice-0.5.0-Fabric.jar` — Use this for Fabric servers (also compatible with Quilt loader).

Notes:

* Do not use the Paper JAR on Fabric/Quilt or the Fabric JAR on Paper/Purpur/Folia.
* Fabric requires Fabric Loader 0.19.5 or newer and Fabric API for Minecraft 26.2.
* Spigot/plain Bukkit remains unsupported for `v0.2.0+`.

* * *

### ⚠️ Upgrade note from v0.4.0

1. Stop the server and back up your PocketDice configuration.
2. Update the server to Minecraft 26.2 and make sure Java 25 is available.
3. On Fabric/Quilt, update the loader and Fabric API for Minecraft 26.2.
4. Replace the old PocketDice JAR with the correct `v0.5.0` JAR for your platform.
5. Start the server.

Config behavior:

* No config reset is required.
* Paper updates `config-version` to `7` and removes both obsolete shorthand keys.
* Fabric stops reading and writing the shorthand setting.
* Shorthand is available even if it was previously disabled.
* Existing locale files remain usable, including custom messages using `{or_d}`.

* * *

### ✨ New

* Minecraft 26.2 compatibility across both platform builds.
* Always-enabled shorthand for `/roll`, `/groll`, and `/proll`; `d8` means `1d8`.

* * *

### Improvements & internals

* Fabric/Quilt builds against Fabric API `0.154.0+26.2`.
* Paper/Purpur/Folia builds against Paper API `26.2.build.48-alpha`.
* Updated invalid-notation messages to include shorthand examples.
* Paper update checks filter out Fabric-only Modrinth releases.
* Added a Minecraft 26.2 build profile that generates matching version and platform metadata.

* * *

### Summary for upgraders

* Use Minecraft 26.2, Java 25, and the correct platform artifact.
* Keep your existing PocketDice configuration and locale files.
* Remove shorthand toggles from custom configuration templates; shorthand is always available.
* For Minecraft 26.3, use PocketDice `v0.6.0`.
