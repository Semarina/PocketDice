### Highlights

* Minecraft 26.3 support for Paper/Purpur/Folia and Fabric/Quilt.
* Dedicated Paper and Fabric builds continue in this release.
* Fabric/Quilt builds against Fabric API `0.161.0+26.3`.
* Paper/Purpur/Folia builds against the stable Paper 26.3 API.
* Includes the always-enabled dice shorthand introduced in `v0.5.0`.
* Java 25 remains required.

* * *

### ⚠️ Platform & artifact selection (IMPORTANT)

`v0.6.0` publishes two JARs for Minecraft 26.3:

* `PocketDice-0.6.0-Paper.jar` — Use this for Paper / Purpur / Folia servers.
* `PocketDice-0.6.0-Fabric.jar` — Use this for Fabric servers (also compatible with Quilt loader).

Notes:

* Do not use the Paper JAR on Fabric/Quilt or the Fabric JAR on Paper/Purpur/Folia.
* Fabric requires Fabric Loader 0.19.5 or newer and Fabric API for Minecraft 26.3.
* Spigot/plain Bukkit remains unsupported for `v0.2.0+`.

* * *

### ⚠️ Upgrade note from v0.5.0

1. Stop the server and back up your PocketDice configuration.
2. Update the server to Minecraft 26.3 and make sure Java 25 is available.
3. On Fabric/Quilt, update Fabric API for Minecraft 26.3.
4. Replace the old PocketDice JAR with the correct `v0.6.0` JAR for your platform.
5. Start the server.

Config behavior:

* No config reset is required.
* No additional config schema change is introduced after `v0.5.0`.
* Dice shorthand remains always enabled.
* When upgrading directly from `v0.4.0`, Paper updates the config to version `7` and removes obsolete shorthand keys; Fabric stops reading and writing those settings.

* Updated `fabric.mod.json` and `plugin.yml` metadata for Minecraft 26.3 and PocketDice `0.6.0`.
* Separate Gradle profiles build both release lines without overwriting the other release's collected JARs.
* GitHub Actions builds both Minecraft targets.
* Updated README and release documentation for both versions.

* * *

### Summary for upgraders

* Use Minecraft 26.3, Java 25, and the correct platform artifact.
* Keep your existing PocketDice configuration and locale files.
* `/roll d8`, `/groll d8`, and `/proll d8` remain available without a configuration toggle.
* For Minecraft 26.2, stay on PocketDice `v0.5.0`.
